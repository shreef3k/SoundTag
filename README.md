# NFT Simulator

Android-приложение на Kotlin + Jetpack Compose: локальный NFT-симулятор с Telegram-подобным интерфейсом.

## Возможности

- Главный экран чатов, контакты и настройки с нижней навигацией.
- Пункт настроек **Мои NFT** со списком локальных NFT-аватаров.
- Создание, редактирование, удаление и выбор активной NFT.
- Локальное хранение через DataStore без сервера.
- Repository-архитектура с `NftRepository` и `FakeRemoteDataSource` для будущей замены локального слоя на REST API.
- Загрузка изображений по URL через Coil 3 с memory/disk cache во внутреннем кэше приложения, чтобы уже загруженные изображения были доступны оффлайн.

## Сборка

```bash
gradle :app:assembleDebug
```

Минимальная версия Android: API 26 (Android 8.0).
